BrightKeys 1.0 (Dual-Language Edition: Română & English)
==========================================================

Control luminozitate și lumină de noapte pentru ambele monitoare, din tastele FN sau scurtături personalizate.
Dual-monitor brightness and per-monitor night light control using FN keys or custom shortcuts.

[RO] CARACTERISTICI PRINCIPALE:
--------------------------------
1. Control individual și simultan al luminii de noapte (Per-Monitor Night Light):
   - Când ținta (Fn+F12) este setată pe „Ambele monitoare”, reglarea luminii calde modifică ambele monitoare simultan.
   - Când ținta este pe „Monitor 1” sau „Monitor 2”, modificarea luminii calde afectează exclusiv acel monitor!
   - OSD-ul animat afișează barele și procentele individuale pentru fiecare monitor (culoare caldă chihlimbar).
2. Suport bilingv complet (Română & Engleză):
   - Meniu rapid de schimbare a limbii în Tray (Limbă / Language -> Română / English) și în Meniul de Setări.
   - Traducere instantanee pentru OSD, meniuri, ferestre de dialog și notificări.
3. Meniu dedicat de setări (Settings Menu):
   - Deschidere cu un click dreapta din iconița din bară → „Setări...”
   - Schimbă limba, pasul de reglare (1%, 2%, 5%, 10%, 15%, 20%), pornirea automată cu Windows.
   - Scurtături globale personalizate: configurează orice combinație dorită (ex: Ctrl+Alt+F9/F10/F12) cu înregistrare directă a tastelor (Key Recorder).
4. Glisare fluidă la 60 FPS:
   - Ține apăsat pe taste pentru reglare continuă și lină, fără sacadare și fără blocaje.

TASTE ȘI COMENZI IMPLICITE:
---------------------------
  Fn+F9           Scade luminozitatea monitorului selectat
  Fn+F10          Crește luminozitatea monitorului selectat
  Fn+F12          Alege monitorul: Ambele monitoare → Monitor 1 → Monitor 2
  Shift + Fn+F12  Activează / Dezactivează Lumina de noapte (Night Light)
  Shift + Fn+F9   Scade căldura luminii de noapte pentru monitorul curent
  Shift + Fn+F10  Crește căldura luminii de noapte pentru monitorul curent

-------------------------------------------------------------------------------

[EN] MAIN FEATURES:
-------------------
1. Per-Monitor Night Light Warmth Control:
   - When target (Fn+F12) is "Both Monitors", adjusting warmth affects both displays.
   - When target is "Monitor 1" or "Monitor 2", warmth is adjusted independently for that monitor only!
   - 60 FPS animated OSD displays distinct per-monitor warmth sliders with warm amber glow.
2. Full Bilingual Support (Romanian & English):
   - Switch language on-the-fly from the Tray menu (Limbă / Language) or the Settings window.
   - Everything translated: OSD, menus, settings, and balloon tooltips.
3. Dedicated Settings Window:
   - Right-click tray icon → "Settings..."
   - Configure language, step size (1%, 2%, 5%, 10%, 15%, 20%), and Windows autostart.
   - Custom global keyboard shortcuts: assign any preferred key combination (e.g. Ctrl+Alt+F9/F10/F12) with built-in Key Recorder.
4. Butter-smooth 60 FPS continuous hold:
   - Hold down keys to glide smoothly across brightness or warmth levels.

DEFAULT HOTKEYS:
----------------
  Fn+F9           Decrease brightness
  Fn+F10          Increase brightness
  Fn+F12          Switch display: Both Monitors → Monitor 1 → Monitor 2
  Shift + Fn+F12  Toggle Night Light On/Off
  Shift + Fn+F9   Decrease Night Light warmth on targeted display
  Shift + Fn+F10  Increase Night Light warmth on targeted display
